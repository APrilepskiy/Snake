# 🐍 Змейка — веб-игра

Классическая «Змейка» на чистом HTML/CSS/JavaScript (Canvas) без зависимостей.

## Возможности
- ⌨️ **Клавиатура**: стрелки / WASD (и ЦФЫВ), Пробел — пауза/старт, R — перезапуск, 1–4 — сложность
- 📱 **Сенсор**: свайпы по игровому полю + экранный D-pad (появляется на устройствах с touch)
- ⏸ **Пауза** и ↻ **перезапуск** кнопками и горячими клавишами
- 🎚 **4 уровня сложности**: Лёгкая / Средняя / Сложная / Безумная (сохраняется между сессиями)
- 🏆 **Текущий и рекордный счёт** (рекорд хранится в `localStorage`)
- ✨ Лёгкие анимации: пульсирующая еда, частицы при поедании, глаза змейки, плавные оверлеи
- 🔊 Звуковые эффекты через WebAudio (без аудиофайлов), кнопка отключения звука
- 📐 Адаптивная вёрстка для настольных компьютеров и мобильных (retina-canvas, `dvh`, `aspect-ratio`)
- Автопауза при переключении вкладки

## Запуск
Просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Файлы
- `index.html` — разметка и стили
- `game.js` — игровая логика и рендеринг
